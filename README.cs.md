# SunamoToNetCore

## Short description

Nástroje pro migraci starších .NET Framework projektů na SDK-style .NET. Rozpoznávají SDK-style projekty, ověřují cílový moniker a obsahují experimentální kód pro hromadnou úpravu web i non-web projektů. Vyčleněno z SunamoDevCode, obsahuje runner i testy.
