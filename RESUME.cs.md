## Description

Nástroje pro migraci starších .NET Framework projektů na moderní SDK-style .NET (Core+), vyčleněné z monolitu `SunamoDevCode`.

Umí rozpoznat, které projekty už jsou SDK-style, ověřit cílový moniker a obsahuje experimentální/výzkumný kód (`research/`) pro hromadnou úpravu web i non-web projektů.

Publikováno na NuGet 2026-09-29.
